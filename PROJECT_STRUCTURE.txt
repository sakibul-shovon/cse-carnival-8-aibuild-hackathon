# CampusOS (AUST Intelligent Campus & Operations Platform)
=========================================================

1. PROJECT OVERVIEW
-------------------
CampusOS is a full-stack smart university campus platform for Ahsanullah University of Science and Technology (AUST).
Built with:
- Backend: Laravel 11 (PHP 8.2+) REST API with Laravel Sanctum & Role-Based Access Control (RBAC).
- Frontend: React 19 SPA, Vite, Tailwind CSS v4, Lucide Icons.
- Database: MySQL / SQLite (Schedules, Rooms, Events, Announcements, Assignments, Users).
- AI Engine: Autonomous Hybrid LLM Agent (OpenAI/Groq/Gemini + Local Tool Execution Engine).

3. ROLE-BASED PERMISSIONS (RBAC)
--------------------------------
- Student:
  * Read-only access to class schedules, rooms, announcements, and assignments.
  * Register for upcoming campus events.
  * Natural language AI queries for room availability, schedules, deadlines, etc.
  * Cannot book rooms, edit schedules, or mutate campus records (Backend enforces HTTP 403).

- Admin:
  * Full CRUD on schedules, rooms, events, announcements, and assignments.
  * Exclusive room reservation & booking capabilities with automated clash detection.
  * Cancel existing room reservations.
  * AI Assistant can execute room bookings on behalf of admins.
